# Design system

Extracted from the code as it is. Values come from `src/app/globals.css`, `src/shared/ui`, and
the feature components. Where the code has no named value, this document says so instead of
inventing one. Read this before planning UI (`ui-plan`) or writing component styles
(`docs/styling.md` covers *how* to style; this covers *with what*).

## 1. Basis

Own primitives, no ready-made component library. Styling is Tailwind CSS v4 utilities plus
CSS Modules for custom effects. Both read the same CSS variables defined in
`src/app/globals.css`, which has a light and a dark (`prefers-color-scheme: dark`) set. The
shared primitives live in `src/shared/ui` (section 3).

## 2. Design tokens

| Role | Value (light / dark) | Name in code |
| --- | --- | --- |
| primary | `#7c3aed` / `#a78bfa`, text on it `#ffffff` / `#0a0a0a` | `--accent` → Tailwind `accent` (`bg-accent`, `text-accent`); `--accent-foreground` → `accent-foreground` |
| danger | `#dc2626` / `#f87171`, text on it `#ffffff` / `#0a0a0a` (4.8:1 / 7.6:1) | `--danger` → Tailwind `danger` (`text-danger`, `border-danger`); `--on-danger` → `on-danger` (the danger button's text) |
| success | `#15803d` / `#4ade80` | `--success` → Tailwind `success` (`border-success`) |
| muted | `#71717a` / `#a1a1aa` | `--muted` → Tailwind `muted` (`text-muted`) |
| spacing step | Tailwind's default scale (0.25rem per step); no project step defined. Most used: page `px-6 py-16`, stacks `gap-4`, controls `px-3 py-2` | no name yet |
| text-size step | Tailwind's default scale, plus one project step: `prose-compact` (15 px), long prose below 640 px. Used: `text-sm`, `text-prose-compact`, `text-lg`, `text-xl`, `text-2xl`, `text-3xl`, `text-4xl` | `--text-prose-compact` in `globals.css` `@theme` → `text-prose-compact` |

Other tokens in the code, outside the four roles:

| Token | Value (light / dark) | Name in code |
| --- | --- | --- |
| background | `#ffffff` / `#0a0a0a` | `--background` → `background` |
| foreground | `#171717` / `#ededed` | `--foreground` → `foreground` |
| surface | `#f4f4f5` / `#18181b` | `--surface` → `surface` |
| border | `#e4e4e7` / `#27272a` | `--border` → `border` |
| fonts | Geist Sans / Geist Mono; Literata 500 and 600 (Georgia, then `serif`, as the fallback) for the home page's headings, loaded in the root layout through `next/font` (Latin and Cyrillic) | `--font-sans`, `--font-mono`; `--font-serif` → Tailwind `font-serif` |
| hero scrim, text on the hero | `rgb(10 10 10 / .60)` / `rgb(0 0 0 / .65)` laid over the hero photo; text `#ffffff` / `#ffffff` (white on the scrim over the lightest photo: at least 5.7:1 light, 7:1 dark) | `--hero-scrim`, read by `HomeHero`'s CSS Module; `--on-hero` → `on-hero` (`ButtonLink`'s `onImage` variant) |
| card | radius 16 px; border, fill and hover fill are the `border`, `background` and `surface` values | `--card-radius` → `rounded-card`; `--card-border` → `border-card-border`; `--card-bg` → `bg-card-bg`; `--card-bg-hover` → `bg-card-bg-hover` |
| section rhythm | 96 px from 1024 px, 80 px from 768 px, 64 px below (vertical padding of a home band) | `--section-y`, used as `py-(--section-y)` |
| measures | text column 896 px, wide column 1152 px | `--measure-text` → `max-w-measure-text`; `--measure-wide` → `max-w-measure-wide` |
| backdrop | `color-mix(in srgb, foreground 40%, transparent)` / `color-mix(in srgb, background 70%, transparent)` (behind a modal dialog, never lightens the page) | `--backdrop`, read by `Dialog`'s CSS Module; no Tailwind name |

The only radius token is the home cards' `--card-radius`; no shadow tokens exist. Other radii are written per component (see section 3).

`danger` and `success` text belongs on `background` only: `danger` on `surface` is 4.39:1 in the
light theme, below WCAG AA for text. Inside an `Alert` the tone colours only the border.
`src/shared/ui/tests/feedback-contrast.test.ts` checks the AA thresholds against these values.

## 4. States

| State | Name in this project | What it looks like |
| --- | --- | --- |
| loading | `Loading` (`src/app/loading.tsx`, route level) | skeleton blocks (`bg-surface animate-pulse`, off under reduced motion) plus a screen-reader-only "Загрузка…" status. Inside components there is no shared pattern (the poem pages' Suspense skeleton, `PoemPageSkeleton`, shared by the public poem page and `/account/poems/<id>`, and the management pages' list and form skeletons repeat the route-level look, skeleton blocks plus a screen-reader-only "Загрузка…" status; the author page's skeleton is blocks only and silent for screen readers; the header's session part shows an empty `min-w-24` placeholder as its `<Suspense>` fallback, with neither "Войти" nor "Выйти"; the admin list's is `AdminListSkeleton`) |
| error | `RootError` (`src/app/error.tsx`, route level) | heading "Что-то пошло не так", muted explanation, optional error digest in mono, and a "Повторить" `Button`. Inside components, a danger `Alert` (form-level and list errors) or an inline `text-danger` paragraph (field errors, the header's sign-out failure) |
| empty | no named component | muted text, e.g. "У автора пока ещё нет публикаций." in the author page's poems section (`AuthorPoemsEntry`), «Никого не нашли» in the admin list (`AdminUserList`) |
| offline | `ConnectionNotice` (save forms only) | a neutral `Alert` above the form and its sending control disabled; a sibling `slow` condition looks the same with its own text. The work board shows it too (`SortableWorkBoard`, handles disabled). Pages themselves have no offline state |

Related route state: `NotFound` (`src/app/not-found.tsx`) shows the heading "Страница не найдена",
muted text, and an accent link back home.
