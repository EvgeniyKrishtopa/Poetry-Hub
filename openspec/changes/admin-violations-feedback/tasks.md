# Tasks

Order: group 1 opens the database (the case table, the new guarded functions, the additive changes to block, ban and the two admin deletes); nothing in the app reads it yet. Group 2 is the email module, independent of the database. Group 3 is the admin feature's server side (DAL, model, Server Actions, and the notice step after the four restricting actions); no screen calls it yet. Group 4 is the `/admin` and `/admin/violations` screens, group 5 the add control on the public pages; both are UI groups and wait for the approved Claude Design link (`docs/claude-design.md`), non-UI groups may proceed. Group 6 is the docs, the About proposal and the final verification. Each group exports only what it already consumes (tests count as consumers for knip) and lands its own tests.
