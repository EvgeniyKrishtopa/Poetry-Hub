State names come from `docs/design-system.md` section 4 (`loading`, `error`, `empty`, `offline`). A home section has no `loading` state of its own: the page is cached, so a section is either rendered or left out (`empty` and `error` both mean the section is absent, FR-7). ## Criteria with a human-visible outcome and where they land

- FR-1 → hero row; FR-2 → featured row; FR-3 → about row; FR-4 → authors row; FR-5 → latest row; FR-6 → closing row; FR-7 → page-level states and every section's absent state; FR-8 → both admin control rows; FR-9 and FR-11 → `/admin/home` row; NFR-2, NFR-3 and NFR-5 → all home rows; NFR-4 → all home rows and the token task (6.2).
- FR-10, FR-12, FR-13, NFR-1 and NFR-6 have no visible outcome of their own.

## Token and variant additions the mockups introduce

All six land in task 6.2 (before → after table is in the `HomeTokens` artboard; light / dark values below). Nothing else in the code uses them yet.

| Token or variant | Before | After (light / dark) |
| --- | --- | --- |
| `--font-serif` | none | Literata 500 and 600, fallback Georgia, then `serif`; the same in both themes |
| `--hero-scrim` | none | `rgb(10 10 10 / .60)` / `rgb(0 0 0 / .65)` |
| `--on-hero` | none | `#ffffff` / `#ffffff` |
| `--card-radius`, `--card-border`, `--card-bg`, `--card-bg-hover` | radii written per component | 16px; `#e4e4e7` / `#27272a`; `#ffffff` / `#0a0a0a`; `#f4f4f5` / `#18181b` |
| `--section-y` | `py-16` on a page | 96 / 80 / 64 px (desktop, tablet, mobile) |
| `--measure-text`, `--measure-wide` | `max-w-4xl` only | 896 px; 1152 px |
| `Button` and `ButtonLink` size `lg`, variant `onImage` | `primary`, `ghost`, `danger`; one size | `lg` is 16/24 with `px-5 py-3`; `onImage` is a white outline over a photo |

## Deviations the mockups raise (decided or open)

- **Admin loading state shows page headings.** Board `AdminHomeA` draws «Главная страница» and the two subheadings over the skeleton rows; the existing admin pages use a bare skeleton with no title so a page does not announce itself to a non-admin. Recorded as an open question in `proposal.md` (owner, due 2026-11-28); until it is answered, build the bare skeleton.
- **Wider grid than the page column.** Cards use a 1152 px measure while text keeps 896 px (`content-width`); the home page's `main` therefore no longer is a single `max-w-4xl` column.
- **The About text, the closing text and every proposed Russian heading** in the mockups are placeholders, as the brief said; the owner confirms them (the copy lives in `home/model` constants).
