# Tasks

Order: group 1 is a spike on the real pages that settles the four things the design could not confirm from the docs (metadata that reads `params` under Cache Components, a 404 status from `notFound()` in `generateMetadata`, `connection()` in a metadata route, and which crawlers Next's default bot list covers). Group 2 is the pure builders in `shared/lib/seo`. Group 3 puts metadata on every page that needs only fixed or Contentful data (root, public static pages, signed-in and auth pages). Group 4 is the data-driven pages (poem, author, collection) with the crawler 404. Group 5 is `robots.txt`, the sitemap and, only if group 1 finds a gap, `htmlLimitedBots`. Group 6 is the docs, the default image and the final verification. None of the groups has a screen of its own (the change adds no visible UI), so there is no Claude Design brief. Each group exports only what it already consumes (tests count as consumers for knip) and lands its own tests. The spike's throwaway edits are undone by restoring backed-up copies from `$TMPDIR`, never by `git checkout` (it would wipe uncommitted group work).
